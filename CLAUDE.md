# ts@rhombus-toolkit

> # PUSHING `main` PUBLISHES
>
> **Every push to `main` starts the release chain**: release-please opens or updates a release PR
> per changed package, and merging that PR publishes the package to npm. There is no staging
> step and no unpublish. **Never push here unless Tom literally says "push" in this session.**
> A "fine", a "whatever", an answered question, or a finished task is not that word. Commit
> locally and stop; the push is the publish.
